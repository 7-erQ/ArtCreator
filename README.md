# ArtCreator

简体中文 | [English](README.en.md)

在屏幕上框选、生成和预览 AI 图片的桌面工具，让游戏素材创作融入当前画面。

## 演示

https://github.com/user-attachments/assets/2f2861ad-3f34-4fac-80fc-73eac947dc80

## 功能

- 屏幕框选与多显示器截图，在指定位置生成素材。
- 直接使用提示词，或结合截图进行 AI 润色，支持中英文。
- 从零生成、多参考图生成和涂鸦局部重绘。
- 接入 OpenAI、LiblibAI 与本地 ComfyUI，支持已保存的 ComfyUI 工作流。
- 批量生成、继续编辑、重新生成与历史图片切换。
- 置顶悬浮预览，支持移动、缩放、克隆和鼠标穿透。
- 复制、保存与拖出 PNG，支持放大、精细处理；透明背景与抠图为实验性能力。
- 通过主页菜单的 Language 选项切换中英文界面，并记住语言选择。
